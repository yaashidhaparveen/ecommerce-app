# E-Commerce Web Application

A full-stack e-commerce web app built during my internship at Thiranex — supports product browsing, cart, checkout, and role-based access for admins and users.

## 🛠️ Tech Stack

Frontend: React (Vite), React Router, Axios
Backend: Node.js, Express.js
Database: PostgreSQL (hosted on Neon)
Authentication: JWT (JSON Web Tokens), bcrypt password hashing

## ✨ Features

- User signup and login with secure password hashing
- JWT-based authentication with role-based access (User/Admin)
- Product catalog with add-to-cart functionality
- Checkout with stock validation and order history
- Admin dashboard for managing products (create, edit, delete)
- Order management backed by database transactions (all-or-nothing checkout)
